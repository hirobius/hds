# Agent topic files

Detail for the rules in `CLAUDE.md` and `AGENTS.md`. One subject per file.
`docs/agents/` (plural) is a different folder: it holds the config that the engineering skills read.

- `autonomy.md`: who decides what, when to push back, how to report.
- `checks-and-merge.md`: the work protocol, GitHub Actions, the local checks, the merge rule.
- `guardrails.md`: the gate registry, the state-surface registry, record freshness.
- `hds-work.md`: sources to read, new components, layout and badge rules, routing documents.
- `figma-sync.md`: the Figma sync flow, the library rule, the staging rule, the call budget.
- `sub-agents.md`: model choice, effort and isolation for parallel sub-agents.
- `lint-fix.md`: how to run an ESLint auto-fix safely.
- `skills.md`: which skill each task type must use, and the tracker config.
- `fleet.md`: the ops hub, issues, `status.json`.
- `pr-previews.md`: screenshots in each pull request.
- `ralph.md`: the autonomous loop: approvals, labels, mechanics.
