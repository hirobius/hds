# HDS 0.31.0: the Roleforge open layout, 1:1

This spec lists every font, token and component change HDS needs so that its default theme, at default density, renders the Roleforge "open layout" preview 1:1. It covers Adrian's two later calls as well: Sora headings on the HDS ramp (hds#850), and the hard-shadow system on the soft filled buttons (hds#888/#889). Section 3 says which patterns HDS ships and which stay in Roleforge, section 4 is the rollout, section 5 is Figma parity, and section 6 lists every place this spec departs from the preview on purpose.

## 0. Summary and decisions

### 0.1 The edit list

1. **Density.** Default density is the target, so Roleforge drops `data-density="compact"`. Below 640, `semantic.space.surface.padding` goes from 28 to 20. Compact stays as an opt-in.
2. **Type.** No new font files. Add weight 600; retune `body`, `ui` and `caption`; add `subtitle`, `bodySm` and `captionSm`; add two tracking values. Headings map onto Sora `title` 28 and `titleSm` 20. Card titles stay Plus Jakarta Sans 600 at 18.
3. **Colour.** Light `surface.raised` becomes graphite-50. New `surface.raisedHover`. The branch's `surface.soft` and `surface.softHover` become _context_ tokens: one tone deeper inside a raised surface. New `popover`, `modal`, `field`, `thumb`, `avatar` and `scrimFill` surfaces. `surface.inverse` becomes neutral-900 / neutral-100 and `content.onAccent` becomes white / neutral-900. Stronger dark subtle and overlay shadows. `shadow.hard` keeps the branch's ink / neutral-500.
4. **Radius.** `semantic.radius.action` goes from 8 to 12, so `rounded-sm/md/lg` become 10, 12 and 16. Dialog, framed EmptyState and the hero take 24. Add `radius.14` for the SegmentedControl track.
5. **Sizes and spacing.** New size primitives 18, 28, 36, 40, 44, 52, 56. Components read their height tokens. Keep `space.px6` and `space.px10` (undo their deprecation from main #781), and add `space.px14`, `space.px18`, `space.9` (36) and `space.14` (56).
6. **Components.** Soft defaults for Button, Tag, SegmentedControl, Tabs (pill), Menu, Dialog, Card, Badge, Disclosure and NavList. New opt-ins: Button `link` and `quiet`, icon-only `shape="circle"`, Input `search`, Select `soft`, Checkbox `round`, Toast `inverse`, EmptyState `framed` and `flat`, Alert `tone="neutral"`, InlineLink `tone="neutral"` and `external`, MetadataList fixed term column, Card `padding="row"`, `layout="entity"` and `Card.Link`. New slots: Tabs `count`, Menu.Item `meta`, Dialog footer `start`, SectionHeader. Fixes: the Input font bug and the disabled icon button's grey tile.
7. **Hard shadow and wipe (D12).** The shadow falls straight down: `0 3px 0` at rest, `0 5px 0` on hover (hover-capable pointers only), `0 1px 0` pressed; the box never moves. It is on primary and secondary, including the secondary buttons that open menus (Status, Sort, Switch track, the place picker, the kit pickers). It is not on tertiary, icon-only, `link`, `quiet` or disabled buttons. The wipe follows the same coverage. Two changes from the branch: icon-only buttons lose the shadow and the wipe, and tertiary loses the wipe.

**Surface context (the tint rule).** In the target, anything inside a card, the hero, a row, a dialog or a framed empty state steps one tone deeper (`--tint` moves from `--surface` to `--surface-2`, `--tint-hover` from `--surface-hover` to `--surface-2-hover`). HDS implements it this way:

- Card, Surface, Dialog content, AlertDialog content, the Disclosure card, the framed **and the flat** EmptyState set `data-hds-surface="raised"`. The flat EmptyState is transparent, but its icon tile and buttons measure #e9e7e8 / #262626 on the white or black page, so it takes the raised context too.
- `build-tokens` emits a `[data-hds-surface="raised"]` block, plus its dark twin under both of HDS's dark selectors. The block re-declares the context tokens (`soft`, `softHover`, `softSelected`, `avatar`) **and every component alias that reads them**: `--component-button-secondary-bg-*`, `--component-tag-*`, `--component-badge-neutral-bg`, the SegmentedControl track. `var()` resolves where a property is declared, so aliases declared on `:root` keep the page value unless they are declared again in the scope.
- **Callout and Alert do not set a context.** They inherit their parent's. The JD card's info Callout holds a secondary sm "Apply suggestions" that measures #e9e7e8 / #262626 on the info background, because the Callout sits in a card.
- Popover and Menu content reset to the page context (soft = #f5f4f4 inside a popover).
- Nesting stops at two tones: a card inside a card stays "raised".
- In tokens.json the raised values live in a new Figma variable collection, "Surface", with modes Page and Raised (§5).

### 1.11 Focus

- **Everything but fields:** `outline: 2px solid border.accent; outline-offset: 2px`, transparent gap (the existing `.hds-focus` rule). Button and the Select trigger move off `ring-2 ring-offset-2 ring-offset-background`, whose 2px gap paints in the _page_ colour and shows as a white halo around a focused button on a #f5f4f4 card. The outline sits outside the hard shadow; nothing moves.
- **Fields:** 2px outline at offset 1, and the border turns `border.accent`.
- **Cards and heads with a stretched control:** the outline goes on the container when the control has `:focus-visible`; the control draws none. Row, job card, template card and JD head: offset 2. Company head: offset 6, radius 12.
- **Menu items:** D3.
