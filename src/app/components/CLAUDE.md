# HDS CORE COMPONENTS - STRICT COMPLIANCE ZONE

You are inside the foundational component library.

1. **Prop Interfaces:** Components here must heavily restrict props.
2. **No Business Logic:** Components must be purely presentational.
3. **Theming:** All components must respect the CSS variables generated by `hirobius.tokens.json`.
4. **Radius scales with the element:** small glyphs → `semantic.radius.control`; controls → `rounded-md` (`semantic.radius.action`); surfaces (anything that holds content: panels, banners, popups, containers) → `rounded-lg`, the same as Card. Nested elements step down so corners stay concentric (inner = outer − padding) and say so with a `radius-ok: <reason>` note. Never `rounded-[…]` or a literal `borderRadius`. A new surface joins `SURFACES` in `scripts/check-surface-radius.mjs`.
