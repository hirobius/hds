# Button

`Button` triggers an action when activated. It's a Radix `Slot`-composable
primitive with `variant`, `tone`, and `size` axes, built with
`class-variance-authority` on top of HDS's Tailwind token bridge.

```tsx
import { Button } from '@hirobius/design-system';

<Button variant="primary">Save changes</Button>;
```

import { ButtonShowcase } from '../components/hds-examples';

## Variants

```tsx
<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="tertiary">Tertiary</Button>
```

## Sizes

```tsx
<Button size="sm">Small</Button>
<Button size="md">Medium</Button>
<Button size="lg">Large</Button>
```

## Tone (status color)

`tone` composes with any `variant` and forces AA-compliant tinted colors in
both light and dark mode:

```tsx
<Button tone="danger">Delete</Button>
<Button tone="success">Approve</Button>
```
