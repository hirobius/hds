## Using tokens directly

```css
.my-component {
  background: var(--semantic-color-surface-raised);
  color: var(--semantic-color-content-primary);
  border: 1px solid var(--semantic-color-border-default);
}
```

Three-tier architecture — primitive → semantic → component — with dark mode
applied via a `[data-theme="dark"]` selector, so the reference chain cascades
with zero JavaScript re-renders.
