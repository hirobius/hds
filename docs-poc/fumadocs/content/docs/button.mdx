title: Button
description: Triggers an action when activated — primary, secondary, and tertiary variants with semantic tone overrides.
---

`Button` is a real, live-rendered `@hirobius/design-system` component —
every example below runs the actual package, styled by the actual token
CSS, not a screenshot or a recreated look-alike.

```tsx
import { Button } from '@hirobius/design-system';

<Button variant="primary">Save changes</Button>;
```

## Tones

Tone applies a token-driven feedback color on top of any variant, and stays
AA-compliant in both light and dark because the fg/bg pair flips together
per theme.

<div className="hds-preview">

  <Button tone="danger">Danger</Button>
  <Button tone="success">Success</Button>
  <Button tone="warning">Warning</Button>
  <Button tone="info">Info</Button>
</div>
