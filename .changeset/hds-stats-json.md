The package ships `public/hds-stats.json`, importable as `@hirobius/design-system/stats.json`: the HDS numbers (public component modules, core components, pattern modules, token total, contrast pairs checked as text and non-text, typography style count, and the product-app / token-level-site split with its source and date) computed from the code by `scripts/build-stats-json.mjs`, regenerated by `pnpm tokens` and `pnpm stats:build`, and checked in `pretest`. Read it instead of typing the numbers (ops#681). The Typography page now says six text styles, as its ramp and the manifest do.
