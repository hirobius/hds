Adds the patterns-subpath codemod (hds#316): `hds-patterns-subpath` (also `node codemods/patterns-subpath.mjs`) rewrites root imports of the 21 deprecated pattern components to `@hirobius/design-system/patterns`, with `--root`, `--check` and `--dry-run`. The deprecation cycle (deprecated in 0.17, removed from the root at 1.0 by default, per hds#254) is documented in the new MIGRATIONS.md, and the README gains an "In use" section with numbers generated by `pnpm consumer:usage`.
