Deprecations reach consumers (hds#469). The package now ships `deprecations.json` at the `./deprecations.json` subpath — every deprecated export, prop, prop value and token with its removal version, plus the 220 names shipped releases already removed — generated by `scripts/build-deprecations.mjs` from the `@deprecated` JSDoc, `hirobius.tokens.json` and the upgrade ledgers, and kept fresh by a pretest check. `hds/no-removed-import` now reads that record's removed list as well as the deprecated-exports record, so importing a name a past release already took away (for example `StatusDot`, removed in 0.21.0) errors once the installed version reaches the release that removed it. A deprecated token's dark and compact re-declarations in the generated token CSS carry the `/* @deprecated */` comment too, and a deprecated `Text` variant value (`heading1`, `docBody`, …) now fires the ADR-014 `warnOnce` runtime warning naming the role it reads as. No component output changes.
