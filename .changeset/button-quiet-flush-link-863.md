Button: `tone="quiet"` sets a tertiary (or link) Button's text to `content.secondary` for a low-priority action beside a primary one, and presses with the 5% wash so the text keeps 4.5:1 in dark. `flush` drops the inline padding so a back link's icon lines up with the heading under it. `variant="link"` is an underlined text action with no fill, padding, hard shadow or wipe, at the size's full height (hds#863). Existing variants and tones render as before.
