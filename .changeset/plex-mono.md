The code font is now IBM Plex Mono 400 (OFL-1.1), replacing Geist Mono. The `primitive.typography.family.mono` token value changes (names unchanged), `fonts.css` ships `ibm-plex-mono-400.woff2` instead of `geist-mono-400.woff2`, and the 13px mono role is unchanged. Figma needs the IBM Plex Mono font installed before `figma:push`.
