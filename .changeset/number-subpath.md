New opt-in subpath `@hirobius/design-system/number` with `NumberValue`: a number that rolls its digits to a new value with the productive motion token, and shows the new value at once under reduced motion. It wraps NumberFlow (MIT); `@number-flow/react` is an optional peer, so install it only if you import this subpath. The main entry does not change (hds#751).
