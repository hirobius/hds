## When to use

- **Broad UI review → `dxe`.** It routes to the specialist skills.
- **Too many controls → `dxe-subtractive-design`.**
- **Layout with real data → `dxe-real-content-design`.**
- **Unclear behaviour → `dxe-interaction-contracts`.**
- **HDS component gaps → `dxe-design-system-evolution`.**

## Limits

- Prose rules an agent applies, not deterministic checks. They do not gate CI.
