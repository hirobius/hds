`pnpm figma:push --delta` now cuts a change too big for one `delta.js` (over 45,000 characters, such as the 57,346-character type ramp) into ordered parts `delta-1-of-N.js` to `delta-N-of-N.js`, so an agent can sync any token change instead of routing it to the Sync plugin. Each part is a complete script with the same guards (library key, `PLAN_CHECKSUM`, `hdsVerifyRuntime`, prune false, no deletion, re-plan to 0), runs only after the part before it (marker `deltaRun` on the file), changes nothing when run again, and writes a receipt that `pnpm figma:snapshot --from-receipt` chains; a plan that fits one script is byte-identical to before. Documented in `figma/README.md` ("More than one part") and ADR-033.
