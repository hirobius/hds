CommandPalette: argument chips for multi-step commands (hds#962, board ops#972). Items can declare `args`; picking one walks its argument steps in the palette, showing the command and each chosen argument as a Tag chip before the field. Arguments with `options` are picked from a filtered list, free-text arguments are taken on Enter; Backspace on an empty field or a chip's remove button steps back. `onSelect` gains an optional second argument (argument id → value) only for commands that declare args — single-step behaviour unchanged. Unit tests + a11y contract tests cover the chip flow (3 new contract ids: argument-chips, chip-backspace, argument-step-announced).
