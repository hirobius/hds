Every page here is generated from the system itself: token tables from `hirobius.tokens.json`, props from the component API, and live examples from the published `@hirobius/design-system` package.

## Install

```bash
pnpm add @hirobius/design-system
```

```tsx
import { Button } from '@hirobius/design-system';
import '@hirobius/design-system/tokens.css'; // design tokens as CSS variables
import '@hirobius/design-system/fonts.css'; // Satoshi and IBM Plex Mono

export const Save = () => <Button variant="primary">Save</Button>;
```
