## Principle

- **One accent.** A single brand color marks the main action, the active item and focus.
- **Plain grays.** Backgrounds, surfaces, borders and text use neutral grays with no warm or cool tint.
- **Status colors mean status.** Error, success, warning and info show what happened. They are not decoration.

## Best practices

- Use the semantic tokens for surfaces, text and borders, so dark mode and brand themes work for free.
- Use the accent for the main action and for selected or focused states.
- Use status colors only for status: alerts, validation, badges.
- Don't write hex, RGB or HSL values in component styles.
- Don't use status colors as decoration or background fills.
- Don't tint the grays.
