# Color

Hirobius is a clean, systems-first visual language that bridges digital precision and physical fabrication through a high-contrast monochromatic palette and a single tenant accent.

## Principle

The color architecture relies on a strict separation between semantic roles and primitive values:

- **One Accent System**: A single brand accent drives primary calls to action, active states, and selected focus indicators across all tenant configurations.
- **Monochromatic Neutrals**: True monochromatic greys provide structural clarity across backgrounds, surfaces, borders, and text without warm or cool tinting.
- **Functional Feedback**: Feedback colors (error, success, warning, info) communicate status and system events exclusively, and are never used as decorative accents.

## Usage Guidance

- Do use semantic color tokens for surfaces, content, and borders to ensure dark mode and tenant compatibility.
- Do rely on the single accent token for primary interactive actions and selected focus states.
- Do restrict feedback colors to functional status indicators and alert banners.

## Don'ts

- Don't hardcode hex, RGB, or HSL values in component styles or prose.
- Don't use feedback colors as decorative accents or background fills.
- Don't tint neutral greys with custom hues or warm/cool overlays.
