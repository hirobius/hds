## Principle

Three typefaces, each with one job:

- **Bricolage Grotesque** sets headings: Bold (700) for display, titles and small titles. Its optical-size axis tightens the letterforms as the size grows.
- **Plus Jakarta Sans** sets everything else people read: Regular (400) for body, Medium (500) for controls and captions.
- **IBM Plex Mono** sets code, token names and ids.

All three are self-hosted under the SIL Open Font License 1.1 and ship in the opt-in `fonts.css`. Without it, headings fall back to Plus Jakarta Sans if you load it yourself, then the system sans. Change the heading face with `--hds-font-family-display` (or `fontFamilyDisplay` on `HdsThemeProvider`); see ADR-063.

## The ramp

Six text styles plus mono. Set one with `<Text variant="…">`, `hds.typeStyles.<role>` or the `.hds-type-<role>` class.

| Role      | Face                | Size / line-height | Weight | Use                                           |
| --------- | ------------------- | ------------------ | ------ | --------------------------------------------- |
| `display` | Bricolage Grotesque | 48 / 1.05          | 700    | One per page, hero only                       |
| `title`   | Bricolage Grotesque | 24 / 1.25          | 700    | Section and card headings                     |
| `titleSm` | Bricolage Grotesque | 18 / 1.375         | 700    | Small heading inside a card or section band   |
| `body`    | Plus Jakarta Sans   | 18 / 1.6           | 400    | Prose                                         |
| `ui`      | Plus Jakarta Sans   | 16 / 1.5           | 500    | Controls, nav, table text, values             |
| `caption` | Plus Jakarta Sans   | 14 / 1.5           | 500    | Metadata, help text and labels, sentence case |
| `mono`    | IBM Plex Mono       | 15 / 1.5           | 400    | Code and ids                                  |

## Best practices

- Set text with the `Text` component so sizes stay on the ramp.
- Use `title` for headings, `titleSm` for the heading of a small band such as a danger zone, `body` for prose and `ui` for controls and labels.
- Use mono only for code, token names and ids.
- Don't use `display` for body text or labels.
- Don't set your own font sizes or line heights.
- Don't mix weights within one set of controls.
