## Principle

Two typefaces, each with one job:

- **Satoshi** sets everything people read: Bold (700) for display and titles, Regular (400) for body, Medium (500) for controls and captions.
- **IBM Plex Mono** sets code, token names and ids.

## The ramp

Five roles plus mono. Set one with `<Text variant="…">`, `hds.typeStyles.<role>` or the `.hds-type-<role>` class.

| Role      | Size / line-height | Weight | Use                                           |
| --------- | ------------------ | ------ | --------------------------------------------- |
| `display` | 48 / 1.05          | 700    | One per page, hero only                       |
| `title`   | 24 / 1.25          | 700    | Section and card headings                     |
| `body`    | 16 / 1.6           | 400    | Prose                                         |
| `ui`      | 14 / 1.5           | 500    | Controls, nav, table text, values             |
| `caption` | 12 / 1.5           | 500    | Metadata, help text and labels, sentence case |
| `mono`    | 13 / 1.5           | 400    | Code and ids                                  |

## Best practices

- Use the `Text` component and semantic typography tokens to maintain consistent hierarchy.
- Follow the defined type ramp for section headings, body prose, and UI labels.
- Reserve monospace typography for code, token names, and technical identifiers.
- Don't use display type styles for body prose or UI labels.
- Don't apply custom font sizes or line-height overrides outside the token ramp.
- Don't mix font weights arbitrarily across UI controls.
