## Principle

Two typefaces, each with one job:

- **Plus Jakarta Sans** sets everything people read: Bold (700) for display, titles and small titles, Regular (400) for body, Medium (500) for controls and captions.
- **IBM Plex Mono** sets code, token names and ids.

## The ramp

Six text styles plus mono. Set one with `<Text variant="…">`, `hds.typeStyles.<role>` or the `.hds-type-<role>` class.

The Tokens section below draws each step in its real font, size and leading, read straight from the tokens.

## Best practices

- Set text with the `Text` component so sizes stay on the ramp.
- Use `title` for headings, `titleSm` for the heading of a small band such as a danger zone, `body` for prose and `ui` for controls and labels.
- Use mono only for code, token names and ids.
- Don't use `display` for body text or labels.
- Don't set your own font sizes or line heights.
- Don't mix weights within one set of controls.
