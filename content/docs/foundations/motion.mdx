## Principle

- **Fast (150ms)** for hover, focus and press.
- **Medium (250ms)** for things that appear: dialogs, menus, toasts.
- **Slow (400ms)** for things that move across the screen.

## Best practices

- Use the fast tokens for hover, focus and press feedback.
- Turn motion off when the user asks for reduced motion.
- Keep transitions short so the app feels quick.
- Don't add bouncy springs to everyday controls.
- Don't use medium or slow motion for simple toggles.
- Don't write durations or easing curves by hand. Use the tokens.
