## Recipes

Use a recipe instead of writing a timing. Spread it on a `motion` element:

```tsx
import { AnimatePresence, motion } from 'motion/react';
import { useMotionRecipe } from '@hirobius/design-system';

function Menu({ open }: { open: boolean }) {
  const recipe = useMotionRecipe('openMenu');
  return <AnimatePresence>{open && <motion.div {...recipe}>…</motion.div>}</AnimatePresence>;
}
```

<MotionRecipesDemo />

| Recipe        | Use it for                                                    |
| ------------- | ------------------------------------------------------------- |
| `openDialog`  | Dialogs and alert dialogs                                     |
| `openMenu`    | Menus, popovers, selects, comboboxes                          |
| `openTooltip` | Tooltips                                                      |
| `toast`       | Toasts arriving in the stack                                  |
| `reveal`      | Content replacing a skeleton (stagger with `staggerDelay(i)`) |
| `swap`        | A label or icon changing in place (key it on the value)       |
| `arrive`      | Saved, sent, done                                             |
| `check`       | A tick drawing itself (an SVG path)                           |
| `shake`       | A field with an error (key it on the error)                   |
| `expand`      | Disclosures and sidebars growing                              |
| `listItem`    | List items entering, leaving and moving                       |

Every recipe has a still version. With reduced motion on, `useMotionRecipe` returns it: things appear and disappear at once, and nothing moves or blurs.

## Springs

Springs come in two families, from Material 3's motion system: **spatial** for things that move (`spatialFast`, `spatialDefault`, `spatialSlow`) and **effects** for fades, colour and blur (`effectsFast`, `effectsDefault`, `effectsSlow`), which never overshoot. `elastic` is the lively one, for arrivals. In CSS each spring is a `linear()` curve (`--primitive-easing-spatialDefault`); in JS it is `hds.motion.springs.spatialDefault`.

## Animated numbers

`NumberValue` rolls a number's digits to its new value with the productive motion token. With reduced motion on, the new value shows at once. It ships only in the `@hirobius/design-system/number` subpath, with `@number-flow/react` (MIT) as an optional peer, so the main entry does not change.

<NumberValueDemo />

```tsx
// pnpm add @number-flow/react
import { NumberValue } from '@hirobius/design-system/number';

<NumberValue value={count} format={{ notation: 'compact' }} />;
```

<PrinciplesAndPractices>

### Principle

HDS feels lively (ADR-065). Every motion must look effective and intentional: it shows where something came from, what changed, or that an action worked.

- **Open and close:** things grow from where they came from, and close faster than they open.
- **Arrive:** a confirmation can land with a small spring overshoot.
- **Swap:** a value that changes in place cross-fades with a slight blur.
- **Fast (150ms)** for hover, focus and press; **medium (250ms)** for things that appear; **slow (400ms)** for things that move across the screen.

### Best practices

- Use a recipe. Don't write durations, curves or offsets by hand.
- Turn movement off when the user asks for reduced motion. The recipes do this for you.
- Springs and a small press scale are fine where they add delight. Save the overshoot for moments that confirm something.
- Don't animate things the user did not act on, and don't loop.
- Don't use medium or slow motion for simple toggles.

</PrinciplesAndPractices>

## Page transitions

`withViewTransition(update)` runs an update inside a [View Transition](https://developer.mozilla.org/docs/Web/API/View_Transition_API) when the browser supports one. Where it doesn't, or when the user asks for reduced motion, the update runs at once with no animation. It takes the update as a callback, so it works with any router or state setter.

```tsx
import { withViewTransition } from '@hirobius/design-system';

function openProject(id: string) {
  withViewTransition(() => setProjectId(id));
}
```

Style the transition with `::view-transition-old(root)` and `::view-transition-new(root)`, and time it with the motion tokens, for example `var(--hds-motion-productive-duration)`.
