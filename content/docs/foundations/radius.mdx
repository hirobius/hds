## Principle

- **Roles, not numbers.** Buttons, inputs and badges use `semantic.radius.action`; small glyphs such as the checkbox box use `semantic.radius.control`.
- **One knob.** Themes reshape the whole system by changing the role, not each component.

## Best practices

- Use the role tokens in components.
- Use `full` only for pills and avatars.
- Don't write pixel radii in component styles.
- Don't mix radii inside one group of controls.
