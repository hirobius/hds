HDS ships to the public npm registry as `@hirobius/design-system`. It is ESM, React 18 or 19, and needs no Tailwind config, router or font files of its own.

## Install

```bash
pnpm add @hirobius/design-system react react-dom
```

`react-router` is an optional peer: add it only if you want HDS links to drive your router.

## Load the CSS once

Import the tokens at your app root. `tokens.css` is the full bundle: the token variables, the theme layer and the utility classes the components use.

```tsx
import '@hirobius/design-system/tokens.css';
import '@hirobius/design-system/fonts.css'; // optional: the HDS typefaces
```

## Mark the HDS scope

Base styles (type baseline, resets) apply only inside an element with `data-hds`, so HDS never restyles the rest of a page you don't own.

```tsx
import { Button } from '@hirobius/design-system';

export const App = () => (
  <div data-hds>
    <Button variant="primary">Get started</Button>
  </div>
);
```

## Theme it with four dials

Theme, density, brand and typeface are root attributes and CSS variables, so they work with no JavaScript, in React, Astro or plain HTML. Every HDS element inside picks them up.

| Dial     | Set with                                      | Values               | Default                          |
| -------- | --------------------------------------------- | -------------------- | -------------------------------- |
| Theme    | `data-theme`                                  | `dark`               | light                            |
| Density  | `data-density`                                | `compact`            | comfortable                      |
| Brand    | `data-brand`                                  | a brand overlay slug | base                             |
| Typeface | `--hds-font-family`, `--hds-font-family-mono` | any font family      | Plus Jakarta Sans, IBM Plex Mono |

In React, [`HdsThemeProvider`](/docs/guides/providers) sets the same attributes with typed props. It is a convenience, not a requirement.

## For agents

The package carries its own agent context: `AGENTS.md` and `llms.txt` at the package root, the component API in `src/app/data/component-api.json`, and `hds-mcp`, an MCP server the package installs as the `hds-mcp` bin (`npx hds-mcp` in a project that depends on it). The full consumer guide is [docs/CONSUMING.md](https://github.com/hirobius/hds/blob/main/docs/CONSUMING.md).
