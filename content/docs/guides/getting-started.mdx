HDS ships to the public npm registry as `@hirobius/design-system`. It is ESM, React 18 or 19, and needs no Tailwind config, router or font files of its own.

## Install

```bash
pnpm add @hirobius/design-system react react-dom
```

Optional peers: `react-router` (router links), `react-hook-form` + `zod` + `@hookform/resolvers` (`/form`), `lenis` (`/scroll`).

## Load the CSS once

Import one stylesheet at your app root:

| Stylesheet      | What it holds                                                                                                 | Use it for                                  |
| --------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| `styles.css`    | Token variables, component styles and utilities. No global reset.                                             | Adding HDS to an existing app. Recommended. |
| `tokens.css`    | Everything in `styles.css`, plus a global reset (Tailwind preflight) that restyles every element on the page. | An app built on HDS from the start.         |
| `variables.css` | The token variables only.                                                                                     | Theming another system from HDS tokens.     |

```tsx
import '@hirobius/design-system/styles.css';
import '@hirobius/design-system/fonts.css'; // optional: the HDS typefaces
```

## Mark the HDS scope

HDS base styles apply only inside `data-hds`.

```tsx
import { Button } from '@hirobius/design-system';

export const App = () => (
  <div data-hds>
    <Button variant="primary">Get started</Button>
  </div>
);
```

Theme, density and brand are root attributes; [`HdsThemeProvider`](/docs/guides/providers) sets them in React.
