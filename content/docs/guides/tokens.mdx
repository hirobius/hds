Every color, space, radius, type and motion value in HDS is defined once, in [`hirobius.tokens.json`](https://github.com/hirobius/hds/blob/main/hirobius.tokens.json). Every other output is generated from it.

## One source, many outputs

The file is [W3C DTCG](https://www.w3.org/community/design-tokens/) format; one build compiles it into:

| Output                                                                                                                             | What it is for                                                                                                                                                                  |
| ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`src/styles/tokens.generated.css`](https://github.com/hirobius/hds/blob/main/src/styles/tokens.generated.css)                     | CSS custom properties, the runtime contract every component reads. They ship on their own as `@hirobius/design-system/variables.css`, and inside `styles.css` and `tokens.css`. |
| [`src/app/design-system/generated-tokens.ts`](https://github.com/hirobius/hds/blob/main/src/app/design-system/generated-tokens.ts) | The same values as typed constants, behind the `hds` object, `tokenValues` and the `ct` dark-mode resolver from `@hirobius/design-system/tokens`.                               |
| [`tailwind.config.tokens.cjs`](https://github.com/hirobius/hds/blob/main/tailwind.config.tokens.cjs)                               | A Tailwind theme projected from the tokens, so utility classes resolve to the same variables.                                                                                   |
| The Figma model                                                                                                                    | Variables for the HDS Figma library. Sync runs one way, from code to Figma.                                                                                                     |
| [`DESIGN.md`](https://github.com/hirobius/hds/blob/main/DESIGN.md), the manifest and `llms.txt`                                    | The visual spec and the machine-readable inventory agents read.                                                                                                                 |

## Tiers

| Tier          | Holds                                                                                                                             | Example                          |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| `primitive.*` | Raw values only: the palette, the spacing scale, font families.                                                                   | `primitive.color.neutral.900`    |
| `semantic.*`  | Purpose: what a value is for, with a Light and a Dark value.                                                                      | `semantic.color.content.primary` |
| `component.*` | One component's use of a semantic value.                                                                                          | `component.button.bgHover`       |
| `role.*`      | Short role names (`--role-background`, `--role-primary`) that alias semantic tokens, for code written against shadcn-style names. | `role.background`                |

Components never read primitives, so a theme only repoints semantic tokens.

## Using tokens

- In CSS, read the variables: `var(--semantic-color-content-primary)`.
- In JavaScript, import them from the tokens entry point:

  ```ts
  import hds, { tokenValues, ct } from '@hirobius/design-system/tokens';
  ```

- No hex, RGB or pixel values in component styles (checks flag them).

## Adding or changing a token

1. Edit `hirobius.tokens.json`: raw values in primitives, aliased by semantic and component tokens.
2. Run `pnpm tokens:verify`.
3. Commit the token file and outputs together. A pair below WCAG AA can't land; rules in [TOKEN_GOVERNANCE.md](https://github.com/hirobius/hds/blob/main/TOKEN_GOVERNANCE.md).
